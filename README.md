# Interactive Visualization Dashboard

## Overview

This project focuses on creating an interactive dashboard using **Power BI** (or Tableau) to analyze employee attrition and identify the key factors influencing employee turnover. The dashboard enables users to explore data dynamically through filters and visualizations, helping organizations make data-driven decisions to improve employee retention.

## Objective

The primary objective of this project is to build an interactive report that answers the question:

**"Why are employees leaving the organization?"**

The dashboard allows users to filter and analyze data based on various employee attributes such as age group, department, job role, education level, and business travel frequency.

## Tools Used

* Power BI / Tableau
* Microsoft Excel / CSV Dataset
* Data Visualization Techniques
* Interactive Filters and Slicers

## Dataset

**HR Employee Attrition Dataset**

The dataset contains employee-related information such as:

* Age
* Department
* Job Role
* Gender
* Monthly Income
* Education
* Years at Company
* Job Satisfaction
* Work-Life Balance
* Attrition Status

### Key Visualizations

* Attrition Rate Overview

### KPIs

* Total Employees
* Employees Left
* Attrition Rate
* Average Monthly Income
* Average Job Satisfaction Score

## Key Insights

* Employees with lower job satisfaction show higher attrition rates.
* Certain departments experience significantly higher employee turnover.
* Younger employees tend to leave more frequently than experienced employees.
* Poor work-life balance is strongly associated with attrition.
* Employees with lower tenure are more likely to resign.
